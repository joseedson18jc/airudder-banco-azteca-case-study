02 · 挑战

一台被人力束缚的催收机器。

同许多拉美大型债权机构一样，Banco Azteca 的催收业务依托于人工坐席、手动外呼以及彼此孤立的提醒流程。结果是：单位成本不断攀升、绩效盲区涌现、产能天花板难以突破 — 每个周期只能触达逾期客户基础的一小部分。

  • 01每日通话量无法实现，受限于人工外呼业务的产能上限。
  • 02运营成本被推高，源于手动外呼和庞大的外呼团队。
  • 03客户基础覆盖有限 — 每个周期只能处理逾期组合的部分客户。
  • 04触达策略不一致，导致参与度低于潜在水平。
  • 05实时可视性不足，难以跟踪各活动的回收 KPI 和 ROI。
  • 06难以协同编排大规模的语音 + SMS 渠道。
核心不只是自动化外呼。而是用一个可弹性扩展、可衡量、实时可审计的引擎，取代原有的产能天花板。

03 · 解决方案

AI 语音坐席 + 自动化 SMS，统一编排。

Banco Azteca 部署了 AI Rudder 的 AI Collections（智能催收）技术栈：用于外呼的预测式上下文语音，结合自动化 SMS 实现全渠道触达。该平台用一个可扩展、合规、高回收率的引擎替代了人工流程 — 每日可运行 250,000+ 通话和 100,000+ SMS。

多边形代表什么

每个轴是巴西企业级催收 RFP 中的一项能力。从中心向外距离范围为 0（不支持）到 100（行业最佳）。多边形的总面积近似于竞争覆盖度 — 面积越大，在交易中守住的侧翼越多。

  • 面积 ≈ 价值覆盖 · 不是某一维度的冠军，而是所有维度上守住的总和。
  • 形状 · "窄"的多边形是脆弱的专精型。"圆而大"的多边形才能赢得 RFP。
  • 催收的关键轴 · 语音 AI + 催收专业化 + 拉美布局 权重更高。

常见问题

试点前通常被问到的问题。

01从签约到生产环境出现首个指标，典型试点周期多长？

封闭范围内 8–12 周：1 个流程（如：分期还款提醒）、1 个渠道（语音或 SMS）、1 个核心 KPI（还款承诺率或回收率）。包括：

  • 第 1–3 周 · 技术集成（外呼器、CRM、核心银行系统、联系人列表）
  • 第 4–6 周 · 巴西葡萄牙语版 AI 语音坐席训练、脚本 A/B 测试、时段校准
  • 第 7–10 周 · 受控放量（目标客户的 10% → 50% → 100%）
  • 第 11–12 周 · 与基线对比的结果分析，做出是否扩展的决策

更简单的试点（1 个 SMS 流程、单一列表）可以在 4–6 周 内完成。

02是否能集成我们的外呼器、CRM、核心银行系统和 WhatsApp Business？

是的 — 巴西常见的所有集成方案均已就绪：

  • 外呼器 · Genesys、Five9、Avaya、Nice、Vocalcom、Dialfire、Hi Platform — REST + SIP
  • CRM · Salesforce、HubSpot、Zoho、Dynamics、Pipedrive — 通过 API 双向同步
  • 核心银行系统 · TOTVS Banking、Fiserv、Temenos T24、Itaú 内部 API — 可定制连接器
  • WhatsApp Business · Meta Cloud API 直连(我们是 Meta 官方业务合作伙伴)，也支持 Twilio、Take Blip、Zenvia
  • 催收数据 · Boa Vista、Serasa Experian、SCPC、Quod — 用于联系人富化和列表检查

新集成通常需要双方共同投入 1–2 周的工程时间。

03在巴西如何处理 LGPD、订阅/退订机制和数据驻留？

该引擎从设计之初就为 LGPD 合规而构建（需客户法务审核）：

  • 合法依据 · 合同履约 + 合法利益 · 在每个客户的 DPA 中记录
  • 结构化退订 · SMS 中"退出"回复、语音中"删除我的号码"自动识别，全平台在 1 小时内同步
  • "勿打扰"名单 + 0303 前缀 · 每次发起前进行交叉名单核对；只在受监管类别中使用 0303 前缀
  • 数据驻留 · 可托管于 AWS 圣保罗（sa-east-1）或 GCP 圣保罗 · 按区域签订独立 DPA
  • 留存与数据主体权利 · 按 CPF 的导出/删除 API + DPO 仪表板

客户在上线前必须执行渗透测试和 LGPD 审计。当前持有 SOC 2 Type II + ISO 27001 认证。

04定价方式是什么？按分钟、按通话还是按座席？

提供三种模式，可以选择最适合您 CFO 的方案：

  • 按接通通话计费 · 每次有人工应答的通话 R$ 0,40–0,80 · 无最低消费 · 适合波动较大的业务
  • 按通话分钟计费 · 每分钟 R$ 0,18–0,30 · 适合较长的探索性对话流程
  • SaaS 许可制 · 按活跃机器人收取月度套餐费 · 在量稳定时可节省 25–40%

SMS：每条 R$ 0,04–0,07（取决于运营商和量）。WhatsApp 通过 Meta 遵循官方价表。需求挖掘阶段免费。

05我们的运营团队学习曲线如何？

试点后运营该引擎的团队小而精 — 通常包括：

  • 1 名产品负责人（50% 投入，负责脚本和流程决策）
  • 1 名运营经理（在仪表板上跟踪每日 KPI）
  • 客户侧 1–2 名工程师按需介入做集成

AI Rudder 提供：1 名专属客户成功经理（中文/葡语支持）+ 新加坡团队 7×24 小时支持。初始培训：2 次 90 分钟的会议，涵盖仪表板、脚本调整、分析读取。无强制认证。

06在巴西或拉美还有谁在用 AI Rudder？

当前在拉美生产环境中运行：Banco Azteca（墨西哥，本案例），以及在墨西哥、哥伦比亚和秘鲁的其他银行和金融科技公司。在巴西，我们与 2 家一级金融科技公司和 1 家零售银行进行封闭式试点 — 参考客户可在需求挖掘周期中通过 NDA 提供。

全球范围：在 25 个国家拥有 200+ 客户，在东南亚（印尼、菲律宾、越南、泰国）、印度、中东和非洲均有活跃业务。投资方：Sequoia Capital、Coatue、Tiger Global。

07如果试点未达到约定的 KPI 怎么办？

试点设计为完全去风险：

  • 在启动会上确定核心 KPI 并有经过审计的基线
  • 双周检查点 — 如果第 6 周仍未收敛，我们会调整范围或停止
  • 试点期间无退出违约金 · 无排他条款
  • 试点期间生成的数据归客户所有（完整导出）

约 85% 的试点能达成或超出 KPI。未达到的 15% 中，通常是名单问题（联系信息过时），我们会在第 3 周识别 — 与语音平台本身无关。
